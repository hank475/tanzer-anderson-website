# Tanzer Anderson Textured HTML Email Standard

This is the canonical visual and delivery standard for Tanzer Anderson email correspondence.

## Required presentation

- Use table-based HTML with inline styles for Gmail and Outlook compatibility.
- Use an ivory outer field, white/ivory content card, restrained navy, and gold rules/details.
- Every outbound message must greet the recipient by first name when known; otherwise greet the named team.
- Display `director@tanzeranderson.com` in the signature and reply pathway.
- Use the title `Managing Director - Strategy and Business Development`.
- Render `Henry Anderson` in gold cursive text using robust system-font fallbacks.
- Include a plain-text fallback.
- Do not require remote images for the core design to render correctly.
- Do not use image-first or pre-rendered correspondence mechanisms.
- Preserve all existing release, approval, candidate-interest, and no-send controls.

## Canonical visual structure

1. Private & Confidential top rule.
2. Tanzer Anderson wordmark in text.
3. Small gold service/context kicker.
4. Personalized greeting.
5. Concise message body.
6. One or two simple HTML CTA buttons when useful.
7. Gold cursive signature, exact title, and `director@tanzeranderson.com`.
8. Navy footer.

All future email-generation and scheduling workflows must use this standard unless Henry explicitly approves a different design for a specific message.
